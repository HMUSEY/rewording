## 2. Chat

Voice: a brief to a capable colleague. One plain opening sentence for the situation, then tagged sections for facts, input, requirements and output. As short as the facts allow.

Paste targets:
- Prompt: (Required)
- Attachments: (Optional, only when the task uses files)

```
[One sentence: the real situation and what I need.]

<context>
[Facts, audience, purpose. Blanks for anything unknown.]
</context>

<input>
[Pasted material, if any.]
</input>

<requirements>
- [Checkable requirement, with a reason when not obvious.]
</requirements>

<output>
[Format, length, language, structure.]
</output>
```

Notes:
- When the user will keep the result, name the output: a doc, a slide deck, a design, a dashboard, or a file format such as .docx or .xlsx. Confirmed artifact types: Docs, Slides, Design (V S50), Dashboards (beta, paid) and Motion (beta, Team and Enterprise) (V S50). Docs and Slides on Free: official pages conflict (T S16, S50). Other types are U.
- File creation is a setting the user can turn off, so a prompt that asks for a file accepts inline output when files are off (V S48).
- Recommend web search or Research only when facts may be newer than June 2026 or cited sources are wanted. Research is on paid plans (V S50).
