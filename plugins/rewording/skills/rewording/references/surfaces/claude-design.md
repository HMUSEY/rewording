## 16. Claude Design brief

Voice: one plain opening sentence with what to make and for whom, then tagged sections.

Paste targets:
- Brief: (Required)
- Reference images: (Optional)

```
Make [screens or pieces] for [purpose] aimed at [audience].

<content>
[Text, data, sections.]
</content>

<brand>
[Colors, fonts, logo rules] [OPTIONAL: default clean neutral style]
</brand>

<avoid>
[Named patterns, e.g. cream backgrounds, purple gradients, pill buttons, stock handshake photos.]
</avoid>

<character>
[The feel wanted, in concrete terms.]
</character>
```

Notes: all plans (V S50). Name the patterns to avoid. A general "avoid a generic look" only swaps one default for another (V S44).
