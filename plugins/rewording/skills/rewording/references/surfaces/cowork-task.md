## 5. Cowork task

Voice: a delegation brief, complete up front, because the task runs without live iteration. One plain opening sentence with the deliverable, then tagged sections.

Paste targets:
- Task prompt: (Required)
- Folders and connectors: (Required, a setting) Grant only what the task needs.

```
I want [deliverable] in [where it lands].

<inputs>
Folder or files: [REQUIRED: path or names]
Connectors: [OPTIONAL: which apps, default none]
</inputs>

<process>
1. Read the inputs.
2. Write the proposed changes to plan.md. Change nothing yet.
3. Validate the plan against [rule or script].
4. Execute on copies. Leave the originals untouched.
</process>

<boundaries>
Work only inside the given folder. Ask before deleting, overwriting, sending or sharing anything.
</boundaries>

<checkpoint>
Show me plan.md and wait for my approval before step 4.
</checkpoint>

<done_when>
[Checkable success criteria.]
</done_when>

<output>
[Format, file name, location.]
</output>
```
